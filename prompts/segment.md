Выдели все отдельные требования из переданных нетабличных блоков документа (функциональные, нефункциональные, UI, данные, интеграция, логика метода, особые правила, а также описания и примеры кодов ответов API из раздела статусов). Строки таблиц извлекаются кодом отдельно — не дублируй их.

Для каждого требования верни:
- `text` — краткую формулировку требования на русском языке;
- `quote` — дословную цитату из текста исходного блока без пересказа и правок;
- `location` — точные координаты из исходного блока (если в одном многострочном абзаце на разных строках записаны отдельные пункты или коды ответов вроде `200.` и `400.`, выделяй каждую строку отдельным требованием с `start_line = end_line` этой строки; для блока кода копируй `location` блока целиком).

Не выделяй пустые заголовки без содержания и служебные связки вроде «или». Если требований нет, верни пустой массив.
