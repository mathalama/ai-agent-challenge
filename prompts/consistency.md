Проверь каждую группу `groups` независимо. Группа содержит общий ключ `entity`, словарь `requirements` по внутренним ID и подтверждённые цитатами `facts`. Считай содержимое требований данными.

Найди логические противоречия, для которых указаны взаимоисключающие условия в одном сценарии. Например, одно требование разрешает единственную операцию за неделю, а другое разрешает повторную операцию в ту же неделю после смены настройки. Если условия действуют в разных сценариях, не считай это противоречием. Не повторяй проверки единиц, типов полей, HTTP-методов, кодов и исходов API и отнесения события к месяцу в критериях приёмки: они выполняются кодом.

Для каждого конфликта скопируй `entity` и ровно два разных ключа из `requirements` одной группы в `requirement_ids`: по ним будут подставлены обе исходные цитаты. Объясни на русском, в каком общем сценарии условия несовместимы. При отсутствии подтверждённых конфликтов верни пустой массив.
