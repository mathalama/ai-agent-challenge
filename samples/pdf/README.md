# Тестовые PDF с разной структурой

Набор для ручной проверки разбора PDF перед сдачей. Содержимое — учебные финтех-ТЗ на русском
с намеренными дефектами (размытые формулировки, противоречия, недоопределённости), чтобы стадиям
проверки было что найти.

Пересоздать (нужен Chrome или Edge, только стандартная библиотека Python):

```sh
python scripts/gen_test_pdfs.py
```

Прогон всех файлов:

```sh
for f in samples/pdf/*.pdf; do cargo run -q -p cli -- check "$f" -o "reports/$(basename "$f" .pdf).md" --provider mock; done
```

## Состав и что проверяет каждый файл

Колонка «Разбор сейчас» — результат на момент генерации (26.11.2026).

| Файл | Структура | Разбор сейчас |
| :--- | :--- | :--- |
| `01-classic-numbered-headings` | ТЗ на 3 страницы: H1–H3, «Общие сведения», списки, колонтитулы и «Страница N из M» | Заголовки и таблица верно, колонтитулы вырезаны. Маркированные и нумерованные списки склеиваются в один абзац (FR-6 + FR-7, пункты 3.3) |
| `02-bordered-tables-merged-cells` | Длинная таблица через страницу с повтором шапки, rowspan/colspan, многострочные ячейки | Верно; таблица через страницу — две таблицы, объединённые ячейки — пустые клетки |
| `03-borderless-tables` | Таблица только с горизонтальными линиями, таблица без линий, «таблица» пробелами | Не распознаются как таблицы: шапка становится H3, строки — абзацами |
| `04-landscape-wide-table` | Альбомная A4, таблица на 10 колонок | Верно, кроме «Тест-кейс» → «Тесткейс» (потерян дефис в ячейке) |
| `05-two-columns` | Две колонки текста | **Сломано**: строки колонок перемешаны, заголовки не на своих местах |
| `06-bold-headings-nested-lists` | Заголовки полужирным обычного кегля, вложенные списки, маркеры • ▪ ○ * – — ✓ 1) а) | Полужирные заголовки распознаются; вложенные списки — абзацы; пункты после `*` слипаются в один элемент |
| `07-api-spec-code-blocks` | API-спека: JSON-блоки, таблица параметров, inline `code` | Блоки кода верно; **абзацы и списки с inline-кодом становятся заголовками H4** |
| `08-mixed-languages-symbols` | Русский + казахский + английский, ₸ € ¥, ≤ ≥, кавычки, мягкий перенос | Верно, но казахская «ә» извлекается как латинская «ə» (U+0259) |
| `09-narrow-hyphenation` | Узкая колонка с автопереносами и составными словами | «антифрод-система» на стыке строк → «антифродсистема» |
| `10-scan-no-text-layer` | Картинка без текстового слоя | Ожидаемая ошибка «PDF не содержит текстового слоя» |
| `11-minimal-one-line` | Одна строка | Верно |
| `12-large-30-pages` | 30 страниц, 15 модулей, 225 требований, колонтитулы | Верно, разбор ~0,3 с; хороший кейс на лимиты и длительность реального LLM-прогона |
| `13-form-footnotes-watermark` | Повёрнутый водяной знак «ПРОЕКТ», сноски, чекбоксы ☑☐, поля «____», TODO, TBD | **Буквы водяного знака становятся заголовками и вклеиваются в текст** («Ррешение») |
| `14-diagram-svg-text` | SVG-схема с подписями внутри блоков, подпись к рисунку | Подписи схемы — отдельные короткие абзацы (шум, но не поломка) |
| `90-truncated-corrupted` | Обрезанный PDF | Ошибка «Не удалось разобрать PDF» |
| `91-not-a-pdf` | HTML с расширением `.pdf` | Ошибка «Не удалось разобрать PDF» |
| `92-empty-file` | Пустой файл | Ошибка «Не удалось разобрать PDF» |

Списки, нарисованные Chrome, не содержат символа маркера в тексте (маркер — графика), поэтому
кейсы 01 и 06 строже, чем PDF из Word, где «•» обычно есть в текстовом слое.
