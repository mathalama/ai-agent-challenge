# Тестовые PDF с разной структурой

Набор для ручной проверки разбора PDF перед сдачей. Содержимое — учебные финтех-ТЗ на русском
с намеренными дефектами (размытые формулировки, противоречия, недоопределённости), чтобы стадиям
проверки было что найти.

Пересоздать (нужен Chrome или Edge, только стандартная библиотека Python):

```sh
python scripts/gen_test_pdfs.py
```

Перегенерируйте PDF только при изменении шаблонов. Браузер обновляет метаданные, включая дату создания, даже при том же HTML.

Прогон всех файлов:

```sh
for f in samples/pdf/*.pdf; do cargo run -q -p cli -- check "$f" -o "reports/$(basename "$f" .pdf).md" --provider mock; done
```

## Состав и что проверяет каждый файл

| Файл | Структура | Разбор сейчас |
| :--- | :--- | :--- |
| `01-classic-numbered-headings` | ТЗ на 3 страницы: H1–H3, «Общие сведения», списки, колонтитулы и «Страница N из M» | Заголовки и таблица извлекаются, колонтитулы удаляются. Соседние абзацы `<p>` с FR-6 и FR-7 сохраняют свои границы. Пункты маркированных и нумерованных списков извлекаются отдельно, в том числе в разделе 3.3 |
| `02-bordered-tables-merged-cells` | Длинная таблица через страницу с повтором шапки, rowspan/colspan, многострочные ячейки | Верно; таблица через страницу — две таблицы, объединённые ячейки — пустые клетки |
| `03-borderless-tables` | Таблица только с горизонтальными линиями, таблица без линий, «таблица» пробелами | Первые две таблицы распознаются по выровненным ячейкам. Секция с табуляцией извлекается как текст |
| `04-landscape-wide-table` | Альбомная A4, таблица на 10 колонок | Все 10 колонок извлекаются, дефис в ячейке «Тест-кейс» сохраняется |
| `05-two-columns` | Две колонки текста | На каждой странице левая колонка читается перед правой. Заголовки разделов идут по порядку |
| `06-bold-headings-nested-lists` | Заголовки полужирным обычного кегля, вложенные списки, маркеры • ▪ ○ * – — ✓ 1) а) | Полужирные заголовки и отдельные пункты вложенных и смешанных списков распознаются |
| `07-api-spec-code-blocks` | API-спека: JSON-блоки, таблица параметров, inline `code` | Моноширинные блоки выделяются как код, inline-код остаётся внутри абзацев и пунктов списка |
| `08-mixed-languages-symbols` | Русский + казахский + английский, ₸ € ¥, ≤ ≥, кавычки, мягкий перенос | Казахские «Ә» и «ә» восстанавливаются в кириллическом контексте |
| `09-narrow-hyphenation` | Узкая колонка с явным мягким переносом «ак- / тивности» и составными словами | «Активности» склеивается без дефиса. Дефис в слове «антифрод-система» сохраняется |
| `10-scan-no-text-layer` | Картинка без текстового слоя | Ожидаемая ошибка «PDF не содержит текстового слоя» |
| `11-minimal-one-line` | Одна строка | Верно |
| `12-large-30-pages` | 30 страниц, 15 модулей, 225 требований, колонтитулы | Верно, разбор ~0,3 с; хороший кейс на лимиты и длительность реального LLM-прогона |
| `13-form-footnotes-watermark` | Повёрнутый водяной знак «ПРОЕКТ», сноски, чекбоксы ☑☐, поля «____», TODO, TBD | Наклонный водяной знак удаляется до разбора текста и таблицы. Сноски и чекбоксы извлекаются |
| `14-diagram-svg-text` | SVG-схема с подписями внутри блоков, подпись к рисунку | Подписи схемы — отдельные короткие абзацы (шум, но не поломка) |
| `90-truncated-corrupted` | Обрезанный PDF | Ошибка «Не удалось разобрать PDF» |
| `91-not-a-pdf` | HTML с расширением `.pdf` | Ошибка «Не удалось разобрать PDF» |
| `92-empty-file` | Пустой файл | Ошибка «Не удалось разобрать PDF» |

В примерах Chrome рисует часть маркеров списков отдельно от текста. Разбор распознаёт такие маркеры по их размеру и положению рядом со строкой.

## PDF-версии документа организаторов

`samples/requirements.pdf` и `samples/requirements.pandoc.pdf` собраны из `samples/requirements.md` двумя независимыми способами. Они нужны, чтобы проверять сквозной прогон на PDF, как в задании.

| Файл | Как собран |
| :--- | :--- |
| `samples/requirements.pdf` | pandoc: Markdown → HTML, затем печать в PDF браузером (Chrome, Edge или Chromium), нумерация «Страница N из M» внизу |
| `samples/requirements.pandoc.pdf` | pandoc напрямую в PDF, движок typst, линии таблиц и разные кегли заголовков |

Пересоздать (нужны pandoc 3.1.2 или новее, typst и браузер; в зависимости проекта они не входят):

```sh
python scripts/gen_requirements_pdfs.py
```

Браузер и typst записывают в PDF дату создания, поэтому файлы отличаются побайтово при каждой генерации. Перегенерируйте их только при изменении `samples/requirements.md` или шаблонов. Тест `crates/review/tests/pdf_samples_parity.rs` сравнивает нарезку требований из PDF и из Markdown.

Известные отличия разбора PDF от Markdown на этих файлах (на нарезку требований не влияют): нумерованные абзацы «200. Ответ…» распознаются как элементы списка без номера, строка «404» полужирным становится заголовком, жёсткие переносы строк абзаца склеиваются пробелом, а таблица на границе страниц без повторённой шапки может распасться на текст.
